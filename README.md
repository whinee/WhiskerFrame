# WhiskerFrame Cyberdeck

WhiskerFrame is an open-source, dual-core cyberdeck pairing a Raspberry Pi Zero 2W host with an ESP32 CYD (Cheap Yellow Display) coprocessor over UART, designed for high-efficiency terminal computing, self-hosted services, and hardware resiliency.
