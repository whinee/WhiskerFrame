## Repository Notes (Lyra's Policy)

1. **Originals vs. Build Outputs:** The published repository contains only the unmodified original art files and the build/conversion scripts.
2. **Derived Outputs:** Device-ready conversion outputs (such as resized frames, `.rgb565` raw pixel buffers, composited shutdown banners, stroke-thickened screen assets, or preview PNGs) are local build artifacts. They are excluded via `.gitignore` and must not be committed to the published repository.
3. **Integrity Verification:** Checksums for all original unmodified files are catalogued in `assets/images/cess/SHA256SUMS`. Checksums must be verified before any commit touching assets. Original files must never be edited in place.
